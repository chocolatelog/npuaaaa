# 通用神经网络处理器多核调度

这是 2026 年研究生数学建模竞赛 A 题的可复现实验代码。当前 `main` 分支保存经过全量实验验证的主版本，核心代码位于 `solver/`，官方评估器和题目输入位于 `通用神经网络处理器下的多核调度问题附件/`。

## 目录

- `solver/`：图模型、构造式初始解、搜索器、代理评估和实验入口。
- `通用神经网络处理器下的多核调度问题附件/code/`：题目官方评估器与验证代码。
- `通用神经网络处理器下的多核调度问题附件/data/`：可复现实验输入。官方生成的超大结果和 trace 不纳入 Git。
- `技术文档.md`：算法设计、模块职责和实验结论。
- `results/`：只保留可审阅的汇总文档和指标摘要；完整原始结果保存在本地实验目录。

## 环境

- Windows 10/11
- Python 3.12
- PyTorch（仅用于 CUDA（统一计算架构）候选筛选）
- 推荐显卡：RTX 3070 8GB

安装依赖后，从项目根目录执行：

```cmd
cd /d J:\数学建模\改进 && python -m solver.run_all --cases 1-100 --cores 2,3,4,5 --scenes A,B --workers 8
```

实验入口带有断点恢复，日志写入 `results/solve_log.jsonl`。完整结果不应提交到 Git，建议使用本地磁盘或对象存储保存。

## 指标口径

- `makespan（总完成时间）`：官方离散事件评估器输出的周期数，越小越好。
- `speedup（加速比）`：基线 makespan 除以当前方案 makespan，越大越好。
- `improvement（改善率）`：`(基线 - 当前方案) / 基线`，越大越好。

主版本采用非回退规则：候选方案经官方评估后，若 makespan 不优于对应基线，则不进入主版本结果。
